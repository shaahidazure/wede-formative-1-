# jxdn Official Website

A modern, responsive HTML website for jxdn (Jaden Hossler), featuring his music, biography, discography, and contact information.

## 📋 Project Overview

This is a multi-page website dedicated to the pop-punk artist jxdn. The site showcases his music career, releases, biographical information, and provides a way for fans and industry professionals to get in touch.

## 📄 Pages

### Home (`home.html`)
- Landing page with hero section
- Latest release feature
- Call-to-action to explore discography

### About (`about.html`)
- Artist biography and background
- Musical style and influences
- Career milestones timeline
- Key achievements and record label information

### Discography (`discography.html`)
- Studio albums section
  - *WHEN THE MUSIC STOPS* (2024)
  - *Tell Me About Tomorrow* (2021)
- Extended Plays (EPs)
  - *28 (Songs for Cooper)* (2022)
- Key singles and features table
- Album artwork and track listings

### Contact (`contact.html`)
- Contact information for:
  - Management & inquiries
  - Booking agent
  - Press & PR
- Interactive contact form with fields for:
  - Name
  - Email
  - Subject (dropdown)
  - Message
- Social media links (Spotify, YouTube, Instagram, TikTok)

## 🎨 Features

- **Responsive Design** - Mobile-friendly layout that adapts to all screen sizes
- **Consistent Navigation** - Easy navigation across all pages with active page highlighting
- **Professional Styling** - Clean, modern CSS styling
- **Semantic HTML** - Properly structured HTML5 markup
- **Accessibility** - Meta descriptions, alt text for images, and semantic elements

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Styling and responsive design
- **JavaScript** - Interactive features (main.js)

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/shaahidazure/wede-formative-1-.git
   cd wede-formative-1-
   ```

2. Open the website:
   - Open `index.html` or `pages/home.html` in your web browser
   - Or use a local server (e.g., Python's `python -m http.server`)

## 📱 Responsive Breakpoints

The website is designed to work on:
- Desktop (1200px and above)
- Tablet (768px - 1199px)
- Mobile (below 768px)
